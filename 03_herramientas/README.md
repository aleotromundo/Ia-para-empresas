# Herramientas — investigación y aprendizaje

Tecnologías candidatas para estudiar y probar. No todas serán adecuadas para todos los clientes.

- **OpenAI:** modelos, asistentes, voz, visión y agentes.
- **Gemini:** modelos y ecosistema de Google.
- **Make:** automatización visual.
- **n8n:** flujos avanzados y opciones de despliegue.
- **Canva:** diseño y contenido.
- **Supabase:** base de datos y backend.
- **WhatsApp Business:** canal de comunicación comercial.
- **Google Sheets:** prototipos y gestión sencilla.

Antes de recomendar una herramienta, verificar capacidades actuales, disponibilidad regional, privacidad, límites, costos y condiciones de uso.
