# Clientes y diagnósticos

Crear una carpeta por cliente y mantener el diagnóstico, oportunidades, propuesta, implementación, pruebas y seguimiento.

## Estructura sugerida
- 01_diagnostico
- 02_oportunidades
- 03_propuesta
- 04_implementacion
- 05_pruebas_resultados
- 06_mantenimiento

Guardar solo los datos necesarios. Obtener autorización antes de conectar sistemas o procesar información del cliente. Anonimizar ejemplos cuando sea posible.
